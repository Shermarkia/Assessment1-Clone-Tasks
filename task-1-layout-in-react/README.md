# Assessment 1: Layout Tasks

Open `index.html` in a browser to see both tasks. No install needed.

## Folder layout

Each task folder has:

- `index.html`: the built page, with React and the CSS inlined. Opens by double-click.
- `app.html` and `src/`: the source.

## Editing a task

Needs Node 18 or newer.

```
cd task-2-responsive-layouts
npm install
npm run dev
```

The browser opens at `http://localhost:5173/app.html` and reloads on save.

When you're done, run `npm run build`. This rebuilds `index.html` from `src/`. Until you run it, `index.html` still shows the old version.
